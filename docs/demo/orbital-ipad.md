# Орбитальная пушка — лист проверки на iPad

Сервер: **192.168.88.85:19132**. Версия аддона: **1.4.0** (выкачена 2026-09-30).

## Как получить Пушку

Любым из двух способов:

1. **Крафт.** Верстак, крест из TNT вокруг удочки:
   ```
    T
   TRT
    T
   ```
   `T` — TNT (4 штуки), `R` — удочка. Пушка в мире одна: если её уже скрафтили, ингредиенты вернутся с сообщением.
2. **Командой:** `/andrew:orbital give` — себе, `/andrew:orbital give <ник>` — другому.

Сбросить «мир уже скрафтил Пушку»: `/andrew:orbital reset`.

## Что проверяем

Отмечай каждый пункт: **да** / **нет** / **не понял**. Где «нет» — своими словами, что увидел.

### 1. Предмет (L0-orbc-ac02)
1. Положи рядом в инвентарь Пушку и обычную удочку — **иконки не отличить**.
2. Возьми в руку — выглядит как удочка.
3. Нажми применение в воздух и по воде — **поплавок не забрасывается**, ничего не ловится.
4. Стол зачарований предмет **не принимает**. Наковальня с зачарованной книгой **не даёт результата**.
5. Creative → «Снаряжение»: Пушка там есть; поиск по слову «Orbital» её находит.
6. Имя показано как «Orbital Cannon» (EN) и «Орбитальная пушка» (RU).
7. Книга рецептов показывает крест из TNT.
   *Нужен скриншот: Пушка в руке.*

### 2. Жесты (L0-orbc-ac08) — самое важное
Встань на ровное место, наведись на блок в 3 блоках.
1. **Касание** по подсвеченному блоку → один залп колец ПКМ **по этому блоку**.
2. **Удержание** по подсвеченному блоку → один столб ЛКМ. Блок при этом **не добывается**, даже если держать дальше.
3. Блок в **8 блоках**, касание → атака по блоку под прицелом.
4. Ни один жест не даёт **двух** выстрелов подряд.
5. Касание по небу — **ни звука, ни текста, ни изменения строки состояния**.
   *Запиши: какая у тебя раскладка управления (обычная сенсорная или с прицелом) и с какого расстояния касание перестаёт попадать по блоку.*

### 3. Строка состояния (L0-orbc-ac10)
1. Держа Пушку, видно `Orbital Cannon — Ready`, по-русски `Орбитальная пушка — Готово`.
2. Сразу после выстрела строка считает секунды вниз: `Орбитальная пушка — 27с`. Тире длинное, пробела перед «с» нет.
3. Обнови язык на второй и проверь обе надписи.
4. Переложи Пушку **во вторую руку** — строка та же.

### 4. Столб ЛКМ (L0-pntr-ac08)
Стреляй удержанием по траве, потом по дну океана, потом в Нижнем мире.
1. Шахта появляется **в тот же миг**, что и грохот, без «расстёгивания» сверху вниз.
2. Стены **рваные**, не ровный квадрат.
3. Слышен **ровно один** громкий взрыв.
4. Волна частиц идёт вниз примерно секунду.
5. В океане вода **заливается** в шахту.
6. Ты, стоя рядом, урона **не получаешь** (упасть в шахту и разбиться — это другое дело, так и должно быть).

### 5. Кольца ПКМ (L0-ring-ai11, ai12, ai15)
Нужен второй игрок: он стреляет, ты смотришь.
1. С **25 блоков**: видно обычное TNT — один по центру и четыре кольца **без разрывов**, появляются разом и падают вместе; на ровном месте рвутся в пределах полусекунды друг от друга; воронки повторяют пять колец. *Нужен скриншот колец в воздухе.*
2. С **20 блоков** по неровному склону, со звуком: слышна **катящаяся серия отдельных взрывов**, а не один бабах; ни одно TNT не улетает вбок или вверх после взрыва соседа; ни одно не остаётся мигать на земле.
3. С **12 блоков** под водой: заряды **тонут** сквозь воду, взрывы слышны, тебя в радиусе задевает уроном, а **дно остаётся без воронок**.

## Чего делать не надо

- Не проверяй урон Пушкой в ближнем бою — он замерен на сервере и равен удару пустой рукой.
- Не проверяй, что заряд не толкает игрока — это тоже замерено.
