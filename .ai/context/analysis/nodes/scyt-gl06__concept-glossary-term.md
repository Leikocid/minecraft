**No-target message** («Здесь нет цели» / "There is no target here")

Key `andrew.scythe.no_target`. The owner's action bar shows it when a Use press finds no visible player **and** no visible mob. It means the ability was not spent: there is no cooldown and no busy (`L0-scyt-r003`). It replaced «Здесь нет игрока» in 0.4.1.
