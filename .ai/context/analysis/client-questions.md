# Q-L0-5 · How far should the Orbital Cannon reach on the iPad?

The spec says both attacks can target a block up to **10 blocks** away, and the normal block outline shows the target.

On the iPad, Minecraft only lets you tap blocks within arm's reach, about 5–6 blocks. This affects **both** attacks, not only the left-click one. The iPad also has a **crosshair layout** (Settings → Touch → "Split controls"). With it you aim at the screen centre, and the add-on can reach 10 blocks for the right-click attack. Left-click beyond arm's reach cannot be detected in either layout.

Which do you prefer?
1. **Arm's reach on touch.** On the default touch layout, both attacks work within arm's reach, and you tap the block you see outlined. With the crosshair layout, the right-click attack reaches 10 blocks. *(Simplest; no new controls.)*
2. **Crosshair layout required for full range.** Same as 1, but the item's tooltip and the guide tell players to switch to "Split controls" to use the full range.
3. **A different gesture for the left-click attack.** For example, crouch + use. With the crosshair layout, both attacks then reach 10 blocks. On default touch they are still limited to arm's reach.
4. **A small particle marker** that shows the aimed block at 6–10 blocks (crosshair layout only), in addition to the normal outline.

Options can be combined (for example 1 + 4). **This blocks the Orbital Cannon core work.** Until you answer, the add-on's default is **1**.
