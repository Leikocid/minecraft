Standalone implementation specification for a Minecraft Bedrock PvP Add-On / Отдельное ТЗ для реализации Minecraft Bedrock PvP Add-On

Version 1.0 --- RU + EN

# 1. Цель / Goal

Создать отдельный тестируемый модуль легендарного оружия «Орбитальная пушка / Orbital Cannon». Предмет должен быть пригоден для дальнейшего переноса в общий PvP Add-On. Реализация должна отдавать приоритет стабильным Bedrock API и серверной надёжности.

Create a standalone, testable legendary weapon module named "Orbital Cannon". It must be suitable for later integration into the full PvP Add-On. Prefer stable Bedrock APIs and multiplayer reliability.

# 2. Основной предмет / Core item

- Название: Орбитальная пушка / Orbital Cannon.

- Внешний вид: ровно как обычная ванильная удочка; отдельная текстура не нужна.

- Базовый предмет рецепта: Fishing Rod.

- Обычная рыбалка полностью отключена.

- Бесконечная прочность.

- Предмет нельзя зачаровать ни через стол зачарований, ни через наковальню.

- Удар по сущности в ближнем бою наносит ровно урон пустой рукой, без дополнительных эффектов.

- Name: Orbital Cannon.

- Appearance: exactly the vanilla Fishing Rod; no custom texture.

- The recipe uses a Fishing Rod as its center item.

- Normal fishing functionality is completely disabled.

- Infinite durability.

- No enchantments via enchanting table or anvil.

- Melee damage must equal an empty-hand punch, with no extra melee effects.

# 3. Рецепт / Recipe

  -----------------------------------------------------------------------
  Empty                   TNT                     Empty
  ----------------------- ----------------------- -----------------------
  TNT                     Fishing Rod             TNT

  Empty                   TNT                     Empty
  -----------------------------------------------------------------------

Результат / Result: 1× Orbital Cannon.

# 4. Уникальный крафт и получение / Unique crafting and acquisition

- В Survival допускается только ОДИН успешный крафт Орбитальной пушки на весь мир/сервер.

- Флаг успешного крафта сохраняется после перезапуска мира/сервера.

- Первый успешный крафт отправляет глобальное локализованное сообщение с названием оружия и именем создателя.

- Копии из Creative и /give разрешены для тестирования и НЕ расходуют/не меняют Survival-флаг уникального крафта.

- Предмет должен быть доступен в Creative Inventory, предпочтительно в Equipment / «Снаряжение», а также через общий поиск/All и /give.

# 5. Передача, смерть и неуничтожимость / Transfer, death and indestructibility

- Оружие не привязано навсегда к создателю: его можно положить в контейнер, выбросить и передать другому игроку.

- Если оружие находится в инвентаре игрока при смерти, оно не выпадает и остаётся/возвращается игроку после возрождения без дублирования.

- Если оружие лежит в контейнере, смерть прежнего владельца ничего с ним не делает.

- Общее правило легендарных оружий: легендарное оружие не должно уничтожаться огнём, лавой, кактусом, TNT, Орбитальной пушкой или другими обычными способами уничтожения item-entity.

- Если легендарное оружие падает в Void, оно возвращается последнему владельцу. Если владелец офлайн, возврат сохраняется и выполняется при следующем входе.

- Если контейнер с легендарным оружием уничтожен, легендарное оружие должно сохраниться/выпасть, а не исчезнуть.

# 6. Наведение и общий кулдаун / Targeting and shared cooldown

- У Орбитальной пушки ровно два режима атаки: ЛКМ (Attack/Hit Block) и ПКМ (Use). На мобильных устройствах использовать ближайшее стабильное соответствие этим действиям.

- Оба режима используют ОДИН общий кулдаун 30 секунд.

- Кулдаун начинается сразу после успешной активации/запуска атаки, а не после попадания.

- Во время кулдауна оба режима заблокированы; повторное нажатие не создаёт заряд.

- Игрок должен навести прицел на блок не дальше 10 блоков. Можно целиться в любую грань блока: верх, низ или бок.

- Если подходящего блока в пределах 10 блоков нет: ничего не происходит, сообщения/звука нет, кулдаун не начинается.

- После активации координаты цели фиксируются и больше не меняются при движении/повороте игрока.

- Дополнительный маркер цели не нужен: используется обычное ванильное выделение блока.
