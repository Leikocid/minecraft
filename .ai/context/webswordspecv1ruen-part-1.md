Цель: отдельная спецификация первого легендарного оружия для Minecraft Bedrock PvP Add-On. Документ рассчитан на независимую разработку и тестирование Web Sword до интеграции с остальными предметами.

# 1. Основные данные / Core

- RU: Паутинный меч. EN: Web Sword.

- Тип: легендарный кастомный меч.

- База: Diamond Sword. Обычный удар должен иметь урон алмазного меча.

- Прочность: бесконечная; предмет не должен ломаться.

- Совместимые ванильные зачарования меча разрешены.

- Предмет должен быть доступен напрямую в Creative Inventory: Equipment / «Снаряжение», общий каталог «Все» и Creative Search. Также должен работать /give.

# 2. Рецепт / Recipe

- Верхний ряд: Empty \| Cobweb \| Empty.

- Средний ряд: Cobweb \| Diamond Sword \| Cobweb.

- Нижний ряд: Empty \| Cobweb \| Empty.

- Результат: 1× Web Sword.

# 3. Уникальный крафт / One-per-world Craft

- В Survival конкретный Web Sword можно успешно скрафтить только один раз на весь мир/сервер.

- Флаг успешного крафта должен сохраняться после выхода игроков, сохранения мира и рестарта сервера.

- После первого успешного крафта повторный survival-крафт должен быть заблокирован без потери ингредиентов, насколько это позволяет стабильный API.

- При первом успешном крафте отправить всем игрокам локализованное сообщение с названием оружия и именем создателя.

- Creative и /give предназначены для тестирования/администрирования и НЕ расходуют право на единственный survival-крафт.

# 4. Сохранение после смерти / Death Retention

- Web Sword владельца не должен выпадать при смерти.

- После возрождения предмет должен вернуться тому же владельцу.

- Реализация обязана предотвращать появление дополнительной копии при смерти, disconnect/reconnect и рестарте.

- Creative/test copies могут существовать у администратора; one-per-world относится к survival crafting, а не к количеству dev/test copies.

# 5. Активная способность / Active Ability

- Активация: стандартное использование предмета (Use / right click / long press, в зависимости от платформы).

- Cooldown: 30 секунд после успешной активации.

- Если корректной цели нет или цель вне допустимой дистанции, способность не срабатывает и cooldown не запускается.

- Дальность: обычная survival interaction/melee reach --- без искусственного дальнего луча.

- Целью может быть точка на блоке, игрок/живая сущность или точка непосредственно рядом с владельцем, если она находится в допустимой reach-зоне.

- В точке цели создать куб обычной паутины (Cobweb) размером 3×3×3, центрированный на целевой позиции.

- Созданная паутина является настоящими обычными cobweb blocks и остаётся в мире, пока игроки не уберут её обычным способом.

# 6. Правила замены блоков / Placement Safety

- Способность может заменить обычные подходящие блоки внутри объёма 3×3×3, чтобы сформировать ловушку.

- Не удалять и не заменять сущности.

- Не заменять контейнеры и функциональные блоки с важным содержимым/данными (например, сундуки и аналогичные block entities).

- Не заменять bedrock и другие явно защищённые/неразрушаемые специальные блоки.

- Если часть куба защищена, пропустить только эти клетки; остальные допустимые клетки всё равно заполнить паутиной.

- Не пытаться создавать паутину вне загруженной/доступной области.

# 7. Обычная атака / Passive Behavior

- У обычного melee-удара нет дополнительного эффекта.

- Обычный удар не создаёт паутину и не запускает cooldown.

- Урон и стандартное боевое поведение --- как у Diamond Sword с учётом применённых совместимых зачарований.

# 8. Cooldown и UI

- Cooldown способности: ровно 30 секунд после успешного создания ловушки.

- При удержании Web Sword игрок должен видеть оставшееся время cooldown через actionbar или ближайший стабильный эквивалент.

- Когда cooldown закончился, способность снова доступна.

- Если в будущем одновременно используются легендарные предметы в обеих руках: готовая способность main hand имеет приоритет; если main-hand способность на cooldown, может сработать готовая off-hand способность.

# 9. Multiplayer

- Способность должна вычисляться серверной логикой, чтобы все игроки видели одинаковый результат.

- Два игрока не должны иметь возможность обойти one-per-world crafting из-за одновременного крафта.

- При одновременной активации несколькими игроками каждый успешный вызов обрабатывается независимо.

- Паутина после создания является общей частью мира и взаимодействует со всеми игроками/мобами по обычным правилам Minecraft.
