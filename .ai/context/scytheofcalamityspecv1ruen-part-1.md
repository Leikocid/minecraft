Краткое отдельное ТЗ для реализации / Compact standalone implementation spec

Version 1.0 --- RU + EN

# 1. Основное / Core

- Легендарное оружие: Коса бедствия / Scythe of Calamity.

- Базовый предмет: Diamond Hoe / Алмазная мотыга.

- Обычный удар в ближнем бою наносит урон как Netherite Sword / Незеритовый меч.

- Бесконечная прочность.

- Совместимые ванильные зачарования базового предмета разрешены, если они не конфликтуют с механикой.

- Действуют общие правила легендарных оружий: один успешный Survival-крафт на мир, сохранение флага после рестарта, глобальное сообщение при первом крафте, сохранение при смерти, Creative и /give для тестирования без расходования Survival-флага.

- Легендарное оружие не должно уничтожаться обычными способами; при падении в Void возвращается последнему владельцу по общим правилам.

# 2. Рецепт / Recipe

  -----------------------------------------------------------------------
  Empty                   Golden Apple            Empty
  ----------------------- ----------------------- -----------------------
  Obsidian                Diamond Hoe             Obsidian

  Empty                   Golden Apple            Empty
  -----------------------------------------------------------------------

Результат / Result: 1× Scythe of Calamity.

# 3. Активная способность / Active ability

- Активация: Use предмета (правый клик / стандартное действие использования; на мобильных --- ближайший стабильный эквивалент).

- Стандартный кулдаун: 30 секунд.

- При активации ищется ближайший видимый PLAYER в радиусе 20 блоков от владельца.

- Мобы не являются целями способности.

- Игрок, скрытый активной способностью Shadow Blade / Теневого клинка, исключается из поиска цели.

- Если несколько подходящих игроков находятся на одинаковом расстоянии, выбирается тот, кто ближе к направлению взгляда владельца.

- Если подходящего игрока нет: показать локализованное сообщение «Здесь нет игрока» / "There is no player here". Способность не расходуется, кулдаун не начинается.

# 4. Три самонаводящихся снаряда / Three homing projectiles

- После успешного выбора цели выпускаются 3 самонаводящихся снаряда.

- Визуал должен напоминать Shulker Bullet, но допускается собственная стабильная реализация частиц/сущностей.

- После захвата цели снаряды преследуют именно выбранного игрока.

- Снаряды проходят сквозь ВСЕ блоки, включая Obsidian, стены, двери и стекло; блоки не разрушаются.

- Каждый снаряд наносит ровно 3 HP (1,5 сердца) TRUE DAMAGE: броня и защитные зачарования не уменьшают этот урон.

- Каждое успешное попадание подбрасывает цель примерно на 10 блоков вверх.

- Обычный урон от последующего падения сохраняется.

- Оставшиеся снаряды могут попасть в цель, пока она уже находится в воздухе.

# 5. Радиус преследования и кулдаун / Pursuit radius and cooldown

- В момент успешной активации запомнить исходную точку владельца --- launch point.

- Снаряды преследуют цель только пока она находится в радиусе 20 блоков от этой исходной точки. Движение самого владельца после запуска не перемещает центр радиуса.

- Если цель выходит за радиус 20 блоков ДО того, как попал хотя бы один снаряд: оставшиеся снаряды исчезают/прекращают атаку, кулдаун отменяется, способность снова готова сразу.

- Если хотя бы один снаряд уже попал, а затем цель выходит за радиус: оставшиеся снаряды исчезают и запускается полный 30-секундный кулдаун.

- После нормального завершения успешной атаки, в которой был хотя бы один хит, действует полный кулдаун 30 секунд.

# 6. UI и руки / UI and hands

- При удержании Косы бедствия в основной или второй руке показывать состояние способности в Action Bar.

- Когда готова: локализованное состояние Ready / «Готово».

- Во время кулдауна: оставшееся время.

- Общее правило приоритета легендарных оружий: если активные легендарные предметы находятся в обеих руках и оба готовы, приоритет у основной руки; если основная рука на кулдауне, готовая способность второй руки может сработать.

# 7. Технические указания / Technical notes

- Предпочитать stable Bedrock Script API; не использовать Preview/Experimental API без необходимости.

- Поиск цели выполнять при активации, а не постоянным тяжёлым сканированием каждый tick.

- Для полёта трёх снарядов допустим короткий временный tick/update только пока они существуют.
